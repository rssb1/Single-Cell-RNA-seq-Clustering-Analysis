Introduction

This project investigates how changing the number of principal components (PCs) affects clustering results in single-cell RNA sequencing data using the Seurat package.

Single-cell RNA sequencing (scRNA-seq) measures gene expression across thousands of individual cells. Because each cell contains expression values for thousands of genes, the data are high-dimensional. Principal component analysis (PCA) is used to reduce this complexity before clustering cells into groups.

The dataset used in this project comes from 10x Genomics: https://www.10xgenomics.com/datasets/10k_5p_Human_diseased_PBMC_ALL_Fix

This dataset contains approximately 10,000 peripheral blood mononuclear cells (PBMCs) from a human donor. These include immune cell types such as T cells, B cells, monocytes, and natural killer (NK) cells. The dataset provides gene expression counts for thousands of genes across individual cells.

Understanding how parameter choices such as the number of principal components affect clustering is important for ensuring that biological conclusions are accurate and not artifacts of analysis settings.

The goal of this project is to answer the following question:

How does changing the number of principal components affect clustering results?

To answer this question, the analysis will:

  • Process single-cell RNA sequencing data using Seurat
  • Perform clustering using 5, 12, and 25 principal components
  • Compare how cluster structure changes across these settings
  • Evaluate whether increasing PCs improves clusterig or introduces noise

Normalize the data

This step normalizes gene expression values across cells.

pbmc <- NormalizeData(pbmc, normalization.method = "LogNormalize", scale.factor=10000)

Normalization ensures that differences between cells are not due to sequencing depth.

Identify highly variable genes (feature selection)

Now that the data are scaled, this code below helps us identify the most highly variable genes across cells. This will help us cluster cells later on.

pbmc <- FindVariableFeatures(pbmc, selection.method="vst",nfeatures = 2000)

Scale the data

We do this as a standard technique for preparing the data for clustering so each gene contributes equally to analysis.

all.genes <- rownames(pbmc)
pbmc <- ScaleData(pbmc, features = all.genes)

Perform linear dimensional reduction

pbmc <- RunPCA(pbmc, features = VariableFeatures(object = pbmc ))
ElbowPlot(pbmc)

The elbow plot shows how much variation each principal component explains in the dataset. The curve begins to flatten after the early principal components, indicating diminishing returns from adding additional PCs.

The values 5, 12, and 25 principal components were selected based on the elbow plot produced during PCA analysis. These values represent regions below, near, and beyond the elbow point, allowing comparison between lower-dimensional clustering, moderate-dimensional clustering, and higher-dimensional clustering that may begin to introduce noise.

The UMAP visualizations showed that increasing the number of principal components caused the clusters to become progressively more separated.

Using 5 principal components produced larger and more connected clusters, with several groups appearing merged together. This suggests that lower-dimensional representations may not capture enough biological variation to fully distinguish all cell populations.

Using 12 principal components increased separation between clusters and produced more clearly defined group boundaries. The clusters appeared more compact and distinct while still maintaining an organized overall structure. This suggests that additional biologically meaningful variation was captured at this intermediate PC setting.

When 25 principal components were used, the clusters became even more split apart and fragmented. Several smaller isolated groups appeared throughout the UMAP space, and the overall clustering structure became more dispersed. While this higher-dimensional representation may capture finer subpopulation structure, some of the additional separation may also reflect noise or over-partitioning of biologically similar cells.

Overall, the results suggest that increasing the number of principal components improves cluster resolution up to a point, after which excessive separation and fragmentation may reduce interpretability.

Discussion

The results showed that the number of principal components strongly influenced clustering behavior in the scRNA-seq dataset.

The elbow plot suggested that the amount of variation explained by additional principal components began decreasing substantially after the early PCs. This provided a useful guide for selecting PC values to test.

When clustering was performed using only 5 principal components, the clusters appeared broader and less separated. Some groups of cells appeared merged together, sugesting that lower-dimensional representations may not capture enough biological variation to fully distinguish cell populations.

Using 12 principal components improved the clustering structure noticeably. The clusters became more clearly separated and more organized, suggesting that additional meaningful variation in the data was captured. This PC value appeared to provide a good balance between preserving biological information and maintaining interpretable cluster structure.

However, when 25 principal components were used, the clustering became more fragmented. Several smaller isolated clusters appeared, and the overall structure became more complex. This suggests that increasing the number of PCs too far beyond the elbow point may begin to introduce noise or over-separate the data.

Overall, the results demonstrate that princpal component selection is an important parameter in single-cell RNA sequencing workflows. Choosing too few PCs can oversimplify the data, while using too many may reduce interpetability by introducing unnecessary complexity.

Conclusions

This project showed that changing the number of principal components can noticeably affect clustering results in single-cell RNA sequencing data. Using too few principal components led to clusters that were less distinct, while using more helped reveal clearer groupings of cells.

At the same time, increasing the number too much did not continue to improve the results. Instead, it made some clusters more fragmented, suggesting that additional principal components can introduce noise.

Based on these results, using an intermediate number of principal components, such as 12 in this analysis, appeared to provide the best balance between capturing meaningful biological variation and maintaining interpretable clustering structure.

Overall, the findings suggest that choosing the number of principal components is an important step that can influence how well the data can be understood.
