# Exploring How Principal Component Selection Influences Clustering Results in scRNA-seq Data

**BINF 3121 Final Project**

This project was completed as the final project for BINF 3121 and investigates how the number of principal components (PCs) used during dimensionality reduction affects clustering outcomes in single-cell RNA sequencing (scRNA-seq) data.

Using a publicly available 10x Genomics peripheral blood mononuclear cell (PBMC) dataset and the Seurat package in R, clustering results generated with 5, 12, and 25 principal components were compared through UMAP visualization, cluster counts, and cluster size distributions.
